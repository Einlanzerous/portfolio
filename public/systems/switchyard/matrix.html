Environment × version — two reads of one page

Queue is the default: services sorted into decisions, the 13 boring ones collapsed to a line. Detailed is the same data as a 27-row table with exact versions and the drift rail. One switch in the page header, sticky per user — both views share the summary segments, the state colour contract, and the row order within a group, so switching never loses your place.

Every pill sits on a fixed invisible column at a uniform 22px, counts cap at 99+, and the gate chip keeps one footprint in all five states (Gate 24/24 · Gate 22/24 · Gate 21/24 · Gate running · No gate). Row actions are one button width.

The switcher works — click Queue / Detailed in any frame below.
